# stock-radar-api

券商分點 / K線分析網站。後端 FastAPI（Render），前端 `index.html`（GitHub Pages）。

## 籌碼鎖定率

公式：**鎖定率 = 主力券商淨買賣超張數 ÷ (發行張數 − 董監持股張數) × 100%**

- **分子＝淨買賣超**（合計買超 − 合計賣超），不是只取買方。代表主力的實際淨吸籌。
- 分母（流通張數）= 已發行普通股 − 董監（內部人）持股。

### 資料來源

| 用途 | 來源 | 備註 |
|---|---|---|
| 排行候選（當日主力買超 top~50/市場） | 富邦 `z/zg/zg_F_{0上市/1上櫃}_1.djhtm` | big5，免上傳 |
| 個股區間淨買賣超 | 富邦 `z/zc/zco/zco.djhtm?a=&e=&f=`（合計買超−合計賣超） | big5 |
| 逐日主力買賣超序列 | 富邦 `z/zc/zco/CZCO.DJBCD?A=代號`（需帶 Referer） | 單行、空白分三段：日期MMDD/股價/主力買賣超 |
| 發行股數（上市） | TWSE OpenAPI `t187ap03_L`（已發行普通股數，最後一欄） | 月更，快取 6h |
| 發行股數（上櫃） | TPEX OpenAPI `mopsfin_t187ap03_O`（`IssueShares`） | 月更 |
| 董監持股（上市/上櫃） | `t187ap11_L` / `mopsfin_t187ap11_O`（內部人「目前持股」） | **須以「姓名」去重**：法人董事佔多席次會重複列同筆持股，naive 加總會灌水到比發行還多（分母變負） |

### API

- `GET /api/vip/chip_lock?market=all|0|1` — 排行篩選，依鎖定率排序（VIP 限定，10 分快取）
- `GET /api/stock/chip_lock?sid=&start=&end=` — 個股指定區間鎖定率
- `GET /api/stock/chip_lock_series?sid=` — 逐日累積鎖定率序列
- 線上 smoke test：`python test_chip_lock.py`

### 前端

- VIP 面板第三模式「🔒 鎖定率」（桌機+手機，可排序、點列載入 K線）
- Tab4 繪圖（日線）：無分點時量能柱顯示主力買賣超、疊青色逐日累積鎖定率線、legend 同步顯示、副圖高度切換（標準/放大/最大）

### 已知限制

1. **逐日鎖定率線僅約 45 個交易日**（受限富邦主力進出圖 DJBCD 範圍）。更長需每日排程預存。
2. **與 XQ 的籌碼鎖定率不會完全一致**：XQ 的主力累積天數與流通定義（是否扣庫藏/政府/特別股）是另一套，本站用已發行普通股 − 董監(內部人)。
3. **排行候選池僅 top~50/市場**：富邦排行頁上限，非全市場掃描；鎖定率低或排名外的個股不會出現在篩選清單（個股端點仍可單獨查任一檔）。
4. **副圖無法拖曳縮放**：lightweight-charts v3.8 的 overlay 軸無可拖曳刻度，改以「副圖高度」選單調整。
5. 校準：發行股數未扣特別股/庫藏；董監為內部人月更快照。
